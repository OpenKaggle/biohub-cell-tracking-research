# Source captures

This directory preserves first-party local decision records byte-for-byte when
they differ in formatting or provenance from the repository's canonical
publication.

`BH-0005-min-track-length.DECISION.md` is the local source capture for the
canonical [BH-0005 decision](../BH-0005-min-track-length.md). The canonical
version adds the repository's public-data boundary; it does not change the
decision recorded in this capture. The capture's original SHA-256 is recorded
in `MANIFEST.sha256`.

These files are decision records only. They contain no competition images,
annotations, row-level tracking outputs, model weights, notebook exports, or
submission bundles. Obtain authorized competition material from the official
source before attempting reproduction.
